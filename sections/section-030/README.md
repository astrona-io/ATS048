# Understanding Prometheus Limitations

This section covers understanding Prometheus Limitations. It develops prometheus Storage, Scale And Evidence Limits through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain scrape gaps and why metrics are not a transaction ledger.
- Relate cardinality, retention and query scope to resource cost.
- Distinguish local storage from remote storage and replication.
- Evaluate monitoring dependencies and failure evidence.
