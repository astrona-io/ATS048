# Summary

A scrape configuration selects endpoints, transport and scheduling. Interval and timeout describe collection behavior, while rule evaluation has a separate schedule. Target labels provide identity and must be reconciled with labels exposed by the producer.

Scrape failure describes the collection path, not a complete application diagnosis. Check discovery, addressing, access and parsing while preserving secure endpoint configuration and the intended target identity.
