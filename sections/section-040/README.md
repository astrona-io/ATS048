# Data Model and Labels

This section covers data Model and Labels. It develops series Identity, Label Cardinality And Staleness through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain how metric names and labels identify a time series.
- Distinguish missing labels, empty labels and matcher behavior.
- Relate changing labels to churn and historical continuity.
- Explain absent samples and staleness without substituting zero automatically.
