# System Architecture

This section covers system Architecture. It develops the Prometheus Collection, Storage And Rule Pipeline through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Trace samples from exposition through scraping and local storage.
- Distinguish query, recording-rule and alert-rule responsibilities.
- Explain Alertmanager's notification role.
- Identify separate failures in collection, processing and remote delivery.
